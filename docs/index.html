Maximum Concurrency

Independent tasks run in parallel using Go Goroutines to maximize your CPU efficiency.

🧠

DAG Engine

Parses dependencies using Kahn's topological sort algorithm to guarantee correct execution order.

🎯

Smart Path Filtering

Automatically skips tasks if their relevant files haven't changed since the last commit.

📦

Zero Dependency

A single, compiled Go binary that won't bloat your project repository with heavy node_modules.

orbit.yaml
version: 1

tasks:
  compile:
    command: "mvn clean compile"
    working_dir: "./backend"
    depends_on: []
    trigger_paths: ["backend/**/*.java"]
    timeout: "2m"

  test:
    command: "mvn test"
    working_dir: "./backend"
    depends_on: ["compile"]
    # Automatically skipped if compile is skipped!
